## *Type Erasure Idiom - Tur Silme*

`std::shared_ptr`, `std::any` ... pek cok sinif *type erasure* teknigini kullaniyor.

Genel amac: Farkli turden nesneleri ayni turdenmis gibi kullanabilmek ve container'da tutmak. Bunun icin *Inheritance* kullanilabilir, fakat bunun icin bastan bir bagimlilik olusturmak gerekir. CRTP kullanildiginda ise containerda tutamayiz.

Burada amac Virtual Dispatch'ten kacmak degil, farkli turden nesneleri ayni turdenmis gibi bir collectionda tutmak.

Implementasyon:

Ilk adim olarak type-erased bir wrapper class olusturulur.

```C++
#include <iostream>
#include <vector>
#include <memory>
#include <concepts>

template<typename T>
concept HasCry = requires(const T& t) {
    {t.cry()} -> std::same_as<void>;
};

class AnyCryable {
    // the hidden interface - Concept
    struct Concept {
        virtual ~Concept() = default;
        virtual void cry()const = 0;
        virtual std::unique_ptr<Concept> clone()const = 0;
    };

    template<HasCry T>
    struct Model final : Concept {
        T obj;

        template<typename U>
        explicit Model(U&& u) : obj(std::forward<U>(u)) {}

        void cry()const override
        {
            obj.cry();
        }

        std::unique_ptr<Concept> clone()const override
        {
            return std::make_unique<Model>(*this);
        }
    };

    std::unique_ptr<Concept> self;
public:
    // constrained forwarding ctor
    template<HasCry U>
    AnyCryable(U&& u) : self(std::make_unique<Model<std::remove_cvref_t<U>>>(std::forward<U>(u))) {}

    AnyCryable(const AnyCryable& other) : self(other.self ? other.self->clone() : nullptr) {}

    AnyCryable& operator=(const AnyCryable& rhs)
    {
        if (this != &rhs) {
            self = rhs.self ? rhs.self->clone() : nullptr;
        }

        return *this;
    }

    AnyCryable(AnyCryable&&)noexcept = default;

    AnyCryable& operator=(AnyCryable&&)noexcept = default;

    void cry()const
    {
        self->cry();
    }
};

class Cat {
public:
    // other members
    void cry()const
    {
        std::cout << "Cat is crying\n";
    }
};

class Dog {
public:
    // other members
    void cry()const
    {
        std::cout << "Dog is crying\n";
    }
};

class Babydoll {
public:
    // other members
    void cry()const
    {
        std::cout << "Babydoll is crying\n";
    }
};

int main()
{
    AnyCryable ac1(Dog{});
    ac1.cry();
    AnyCryable ac2(Cat{});
    ac2.cry();
    AnyCryable ac3(Babydoll{});
    ac3.cry();

    std::vector<AnyCryable> vec;
    Dog mydog;
    Cat mycat;
    vec.push_back(mycat);
    vec.push_back(mydog);
    vec.push_back(Babydoll{});

    for (const auto& cryable : vec) {
        cryable.cry();
    }
}
```
