## ***Fold Expressions***

Oyle bir ifade ki; parametre pakedinin kullanildigi templatelerde, belirli sentaksa gore operatorlerle kullanildigi zaman parametreleri operatorlerin operandi olacak bir ifadeye donusturur.

> Fold Expression kategorileri:
> - *Unary Fold Expression*:
>   - *Unary Left Fold*
>   - *Unary Right Fold*
> - *Binary Fold Expression*:
>   - *Binary Left Fold*
>   - *Binary Right Fold*

Bunlarin hepsi binary operatorler icin kullanilan ifadeler. Yani bu ifadelerin hepsinin icinde bir binary operator olmak zorunda.

Sentaks:
Mutlaka bir parantez icinde yazilmak zorunda.
Mutlaka bir binary operator bulunmak zorunda.
Unary fold demek: Operantlardan biri parametre paketi, digeri elipsis atomu olacak.

> - `...` paketin solunda ise left fold.
> - `...` paketin saginda ise right fold.

```cpp
template<typename ...Ts>
void func(Ts ...args)
{
    // (args + ...) unary right fold
    // (... + args) unary left fold
}
```

Unary left fold icin derleyicinin yaptigi cikarim:

```cpp
template<typename ...Ts>
void func(Ts ...args)
{
    (... + args);
    // ((p1 + p2) + p3) + p4;
}

int main()
{
    func(1, 4, 6, 8);
}
```

```cpp
template<typename ...Ts>
constexpr auto sum(Ts ...args)
{
    return (... + args);
}

int main()
{
    constexpr auto result = sum(1, 5, 8, 9, 2);
}
```

Unary right fold icin derleyicinin yaptigi cikarim:

```cpp
template<typename ...Ts>
void func(Ts ...args)
{
    (args + ...);
    // p1 + (p2 + (p3 + p4));
}

{
    func(1, 4, 6, 8);
}
```

### ***Binary Fold***

Ifadenin binary fold mu yoksa unary fold mu oldugunu, ifadenin icinde bir veya iki operator olmasindan anlarsiniz.

> - `(args + ...)` Unary Right Fold
> - `(... + args)` Unary Left Fold
> - `(args + ... + val)` Binary Right Fold -> `p1 + (p2 + (p3 + (p4 + val)))`
> - `(val + ... + args)` Binary Left Fold -> `(((val + p1) + p2) + p3) + p4`

```cpp
#include <iostream>

template<typename T, typename ...Ts>
constexpr auto sum(T val, Ts ...args)
{
    return (val + ... + args);
}

int main()
{
    using namespace std::literals;
    std::cout << sum(1, 3, 5, 7) << '\n';
    std::cout << sum("murat"s, "ali", "veli", "can") << '\n';
}

/* 
    Out:
    16
    muratalivelican
*/
```

Buraya kadar gosterilen orneklerden hicbiri "*neden binary fold expression kullanmaliyim*" sorusunun cevabi degil.

Nedenlerden biri paketin bos olma senaryosu.

Parametre paketinin bos oldugu durumlarda Unary Fold ifadeleri yalnizca su operatorler ustune kullanildiginda legaldir:
- `&&` -> Bosken `true` dondurur.
- `||` -> Bosken `false` dondurur.
- `,` -> Bosken `void` dondurur.

```cpp
#include <iostream>

template<int ...VALS>
constexpr auto x = (... + VALS);

template<int ...VALS>
constexpr auto y = (... && VALS);

template<int ...VALS>
constexpr auto z = (... || VALS);

int main()
{
    // constexpr auto valx = x<>; // Error.
    constexpr auto valy = y<>; // true
    constexpr auto valz = z<>; // false
}
```

Binary fold olmasi durumunda paket bos olsa dahi sentaks hatasi olmayacak:

```cpp

{
    return (0 + ... + args);
}

{
    auto val = sum();
}
```

```cpp

{
    return (val - ... - args);
}

int main()
{
    constexpr auto val = substract(100, 12, 23, 15, 9, 8); // 33
}
```
